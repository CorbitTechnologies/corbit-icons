# Corbit Icons

A premium icon package for Flutter, featuring 50+ sharp, professional icons from Corbit Technologies.

## Installation

Add `corbit_icons` to your `pubspec.yaml`:

```yaml
dependencies:
  corbit_icons: ^1.0.0
```

Or run:

```bash
flutter pub add corbit_icons
```

## Usage

```dart
import 'package:corbit_icons/corbit_icons.dart';

// ...
Icon(Corbit.home)
// ...
```

## Icons

Includes 50+ icons including:
- Home
- Search
- Settings
- User
- And many more...
