# Corbit Icons React

Premium, vibe-coded React icon components for Corbit Technologies.

## Installation

```bash
npm install corbit-icons-react
```

## Usage

```jsx
import { Home, Search, Bell } from 'corbit-icons-react';

function App() {
  return (
    <div>
      <Home size={24} color="blue" />
      <Search />
      <Bell />
    </div>
  );
}
```
